# Scripts vidéo — campagne « Facture. Encaisse. Respire. »

Chaque script donne : la **voix off** (texte exact, lu tel quel), les **textes à l'écran** et **ce qu'on voit** (captures réelles de Margokit sur un compte de démonstration fictif « Studio Atlas », Casablanca).
Les durées sont indicatives ; la voix off fait foi. Tous les chiffres sont fictifs mais calculés par l'application.

Règles de ton : tutoiement, phrases courtes, un verbe d'action par phrase, aucune promesse invérifiable. La 1re seconde montre le problème, pas le logo.
